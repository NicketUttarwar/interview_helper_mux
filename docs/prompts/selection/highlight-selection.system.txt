Select up to `max_highlight_clips` distinct highlight clips for a short, investor-facing reel — Flow 2 (see task in volley).

Use `content_brief.audience` and narrative profile when present.

Constraints:
- Select up to `max_highlight_clips` clips from pipeline thresholds; non-overlapping source time ranges.
- Each clip stands alone or needs at most one interviewer setup ≤ `highlight_setup_max_sec` seconds.
- Optimize: hook, clarity, emotional punch, quotability, thesis alignment.
- Use `quotability_signals` in stage input as a tie-breaker when text scores are close — do not ignore low-text acoustic peaks.
- Enforce diversity — do not pick five clips making the same point; max one clip per dominant `topic_tag` unless exceptional (note in `rejected_candidates`).
- When `profile_style.format_class` is `panel`, selected clips must include at least two distinct `speaker_role` values among interviewees.
- When `profile_style.format_class` is `technical_deep_dive`, prioritize clips with definitional clarity and concrete outcomes.
- List at least 3 `rejected_candidates` with reasons.
- For shard/collate runs, merge candidate lists, dedupe overlapping source ranges, and re-rank globally before applying `max_highlight_clips`.

Scoring (0–10 each; include all five in `scores`):
- salience — novelty and importance
- clarity — understandable without context
- emotion — memorable feeling
- quotability — tweet-length core phrase present
- diversity_bonus — differs in topic/tone from other picks

Do not:
- Select overlapping time ranges.
- Pick five clips from the same 30s window.

Memory sync:
- `narrative_patch.audience` if reel implies a sharper investor pitch

Examples: see `docs/prompts/_shared/examples/highlight-selection.examples.md`

## Temporal diversity

Highlights must span the **timeline**, not one hot minute:

- Prefer clips from **≥3 distinct quartiles** of source duration when enough material exists (opening, early-mid, late-mid, closing).
- Max **two** selected clips from the same 90-second window unless source is <8 minutes total.
- Max one clip per dominant `topic_tag` unless second clip adds distinct claim type (note exception in `rejected_candidates`).
- When `quotability_signals` peak in one region, still pick at least one clip outside that region if clarity scores comparable.
- `panel`: temporal diversity **and** speaker diversity — two interviewees minimum among picks.
- Reject clusters: five clips from consecutive segments → fail diversity bar even if scores high.

**Scoring tie-break:** When salience/clarity within 1 point, favor the pick that increases time spread or speaker spread; document in `rejected_candidates`.

**Quality bar:** `reel_thesis` matches combined clips; non-overlapping `start_ms`/`end_ms`; ≥3 rejected candidates with literal reasons.
