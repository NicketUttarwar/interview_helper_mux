Audit whether every theme and claim from the content brief is represented in the segment manifest (see task in volley).

Goals:
- Map each `content_brief` topic and `key_claim` to at least one `segment_id`.
- Weight `emphasis_regions` when present — quiet-but-vital acoustic emphasis may indicate under-mapped claims.
- Flag topics with zero coverage in `missing_coverage` with a concrete `suggestion` (required for excludes).
- Flag segments that cover no brief topic in `orphan_segment_ids`.
- Prefer including all non-aside interview material in the eventual full master.
- When `content_brief.topic_relationships` is present, verify `evidence_segment_ids` are covered or note gaps in `missing_coverage`.
- For shard/collate runs, merge mappings across shards, dedupe by topic/claim text, union all supporting `segment_id`s, then recompute one global `coverage_score`.
- If `content_brief.key_claims` is non-empty, return `claim_mappings` for every claim.

Coverage score (required):
- `coverage_score` = (topics covered + claims covered) / (total topics + total claims), clamped 0–1.
- Count a topic/claim covered if `covered: true` and `segment_ids` non-empty.

Do not:
- Mark covered without a real `segment_id`.
- Ignore claims from the brief.
- Omit `suggestion` on any `missing_coverage` exclude.

Memory sync:
- `confidence_patch`: `{ "coverage": coverage_score }`

Investigations / needs:
- For each `missing_coverage` item, add `follow_up_investigations` kind `theme_unmapped` → `segment_classification`, or `needs` `rerun_stage` if blocking.

Examples: see `docs/prompts/_shared/examples/topic-coverage-audit.examples.md`

Schema: `artifacts` → `docs/cross-cutting/json-schemas/artifacts/coverage_audit_artifact.schema.json`

Place this stage artifact inside the required envelope as `artifacts`:

## emphasis_regions — acoustic weight

When stage input includes `emphasis_regions` (operator or acoustic analysis):

- Each region has `segment_id` and/or time range with emphasis score — treat **high emphasis + low brief mapping** as under-covered claims or beats.
- Cross-check emphasis peaks against `key_claims` and `emotional_beats`; if a loud/energetic moment supports a claim with empty `claim_mappings`, add mapping or flag `missing_coverage` with `suggestion`.
- Quiet but vital speech: low RMS yet high semantic weight (definitions, numbers) — do not ignore because emphasis score is low; rely on brief + manifest text.
- Weight `coverage_score` downward (by 0.05–0.15) when high-emphasis regions map to no topic or claim unless `orphan_segment_ids` explains them as aside/reaction.
- Emit `follow_up_investigations` `theme_unmapped` when emphasis aligns with a brief topic name but zero `segment_ids` in mapping.

**Shard collate:** Union emphasis-overlap segment ids into claim/topic mappings before scoring.

**Quality bar:** `suggestion` on every `missing_coverage` row must name segment **type** or search strategy ("look for `setup` before seg_042", "re-tag manifest for topic X") — never "cover better".

## coherence_summary — long-run drift (H-ORC-03)

When stage input includes `coherence_summary` (30m+ interviews only):

- Treat `risks[]` with `kind: topic_drift` as candidate under-mapped hinge points — cross-check `topic_mappings` and `missing_coverage`.
- Use `missing_callback` risks to prioritize topics that need second-half segment_ids or documented excludes.
- Do not duplicate spine speaker-turn hints; coherence risks are composite (theme + acoustic novelty).
- Cap: at most 5 risk rows in volley input — reconcile with brief topics by name/id.
