Compose one flagship episode preface that clusters deferred and gap-fill nuggets into a cohesive cold open.

Input: ranked `nugget_ids`, nugget claims, content brief thesis/guest, coverage gap, word budget (~90 words). When `episode_card` is present, it is analysis-only: match the preface diction to that description of the whole conversation, never paste the card into `text`, and do not add a JSON key.

Goals:
- 2–4 clustered facts with an intriguing hook — softened paraphrase, not a verbatim list.
- One speakable `episode_preface` that orients who/what/why before the first native. End freely when the orientation is complete — no required hinge or quiz closer.
- Pack as many supplied nuggets as fit organically; prioritize high-salience claims.
- Prefer brief thesis + stakes; guest name once when present in the brief.

Do not:
- Reference pipeline artifacts, chapters, clips, or edit metadata.
- Invent facts beyond supplied nuggets and brief.
- End with abstract rhetorical questions (“What does X ask/reveal/mean…?”).

Output envelope artifact:

{
  "text": "full speakable intro preface",
  "nugget_ids": ["nug_001", "nug_002"],
  "clustered_themes": ["theme one", "theme two"],
  "rationale": "why these nuggets cluster for the open",
  "intro_nugget_recovery": true
}
