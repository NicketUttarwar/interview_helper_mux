Compose **pre-native synthetic VO lay-ups** for kept ordered segments — only when they earn airtime.

You receive: `nugget_corpus` (canonical claims/evidence by `nugget_id`), plus one `natives[]` row per ordered segment in this call — `text` / `comprehensible_text` (the upcoming native beat **T**), `prior_closing_excerpt` (how the immediately prior native beat ended), `seam_reason` / `handoff_need` (why the listener needs help entering T), `opening_owner` (true when episode orientation owns that before-slot), `open_nuggets_ranked` (still-unaired corpus nuggets ranked for T — often slim id/score pointers; look up claim text in `nugget_corpus`), and `already_aired_nugget_ids` / `already_claimed_facts` (facts already spent earlier in the air order). When `_layup_compose_shard` is present, compose **only** for the natives in this shard. Honor packet-root `opening_owned_segment_ids`.

Do **not** emit `order_lock` or `order_content_hash` — code stamps them from selection after compose.

## First-time listener (hard)

Assume the listener knows nothing about editing, selection, chapters, acts, missions, talking points, scopes, coverage, pipelines, or planner fields. Spoken `text` must make sense on its own as podcast host speech: grounded people/places/stakes/facts plus a concrete unlock into T. Never force the listener to decode production language.

## Omit unless useful (default)

Attempt a decision for **every** `ordered_segment_id`, but **prefer typed skip** when:
- The prior native already hands off cleanly (especially interviewer question → interviewee answer).
- T is self-explanatory from prior context alone.
- No unrecovered high-salience / eligible unspent nugget remains for T.
- Opening orientation already owns the before-slot (`opening_owner` / `opening_owned_segment_ids`).
- Any candidate air copy would be vague, meta, or only restate T.

**Hard — do not skip high-salience holes.** You may **not** skip with `no_eligible_unspent_nugget`, `no_unrecovered_high_salience`, or `self_explanatory_native` when `open_nuggets_ranked` still contains a high or critical nugget for T. Air that fact, or place the line on the next native that is not the cloned host speaker. Sparse placement is for seams with nothing left to recover — not for leaving corpus claims on the table.

Air a lay-up only when it recovers unaired high-value excluded-tape facts **or** supplies a genuine conversational bridge a first-time listener needs. Sparse strategic placement beats dense coverage.

When `degraded_lexicon_island` / `degraded_path` is true (or `transcript_quality` is degraded):
- Build setup only from `comprehensible_text` / `high_conf_text` + grounded corpus nuggets.
- Treat `unclear_spans` as awareness only (“dense unclear stretch”) — never invent what those tokens said.
- Work around missing context; keep a smooth forward unlock into T; do not apologize on air or say “unclear audio.”
- Air `text` must stay speakable (no bracket placeholders). Thinner unlocks are OK when island meaning cannot be recovered. Prefer skip if you cannot form grounded useful copy.

For **each** `ordered_segment_id`, emit one `layups[]` row that is either a contentful air line *constructed for the next native*, or a typed skip:
- `target_beat` — what T actually delivers (one clause, listener-facing). Analysis only — never paste into `text` as meta.
- `listener_need_entering_T` — the specific contextual gap a listener has at that seam (use `handoff_need` / `prior_closing_excerpt` + `seam_reason`). Describe the **topic / fact / stakes**, never edit structure. Analysis only — never paste planner prose into `text`.
- `selected_nugget_ids` — the nuggets this line spends (prefer `in_selection: false`, high-relevance, still open). Never reuse anything in `already_aired_nugget_ids`.
- `setup_from_nuggets` — the recovered facts as host paraphrase, faithful to the evidence quotes.
- `forward_unlock` — the concrete, T-specific reason to keep listening.
- `text` — the spoken line built from `setup_from_nuggets` + `forward_unlock` (`forward_cue_ok: true`). Never copy `listener_need_entering_T` or `target_beat` verbatim into air.
- When T is spoken by the same person as the cloned host VO, emit a lay-up only when its selected nuggets recover high-salience or excluded-tape facts. Code retargets that line onto the next non-clone native (or merges into that dest). Generic host framing before that same speaker is skipped, not relocated.
- Skip with a **typed** decision — never bare `skip: true`. When skipping, set `skip: true` plus:
  - `skip_reason_code` (closed enum) — prefer `self_explanatory_native`, `native_self_orients`, `listener_already_oriented`, `no_unrecovered_high_salience`, `no_eligible_unspent_nugget`, `opening_orientation_owns_target`
  - `evidence_refs[]`
  - `value_forgone[]` (nugget / talking-point ids left unaired)
  - `compensating_path` (what covers the listener need instead)
  - `revisit_if[]`
  - `decision_confidence` (0–1)
  - `owner_stage` (`nugget_layup_compose`)
  Prefer skip when `opening_owner` is true (`opening_orientation_owns_target` + compensating_path `opening_orientation`).
- Cite which `nugget_ids` (and optional `talking_point_ids`) the line discharges.
- Host paraphrase only — never invent dialogue or credentials; stay faithful to evidence quotes.
- Keep word count inside the stage input budgets (`min_layup_words` / `max_layup_words`; `dense_max_layup_words` for information-package targets).

Hard rejects (QC fails the stage):
- Canned or interchangeable air copy — anything in `banned_air_phrases`, and generic unlocks such as “What changed after that?”, “What happened next?”, “What shifted from there?”. Every unlock must name something only T can answer.
- A line missing `target_beat`, `listener_need_entering_T`, or `forward_unlock` when not skipped.
- Restating T’s own content (the listener hears it seconds later) or reusing another lay-up’s wording or complete sentence.
- The same `nugget_id` claimed by two lay-ups.
- Any show scaffolding or master-construction language: “welcome back”, “chapter”, “after the break”, “previous clip”, “earlier segment”, “next segment”, “this clip”, “that segment”, spoken segment/line/clip IDs, pipeline/artifact/EDL/metadata terms.
- Planner / analysis leakage into air: “intended scope”, “episode scope”, “native continuation”, “listener need”, “talking point”, “vo mission”, “coverage of this conversation/episode”, or any phrase that only makes sense to an editor.
- Spoken copy may only convey grounded contextual facts (people, places, time, causal stakes, recovered nugget claims) plus a layup into the next native beat. If you lack that evidence, omit / skip — never invent a relative filler bridge.

Also emit ledger fields:
- `discharged_talking_point_ids` / `open_talking_point_ids`
- `discharged_nugget_ids` / `open_high_salience_nugget_ids`
- `waived_nugget_ids` only with explicit reasons

Ideal: try every seam; air sparsely. Coverage floors are soft floors for high-value recovery — not a mandate to speak before almost every native.
