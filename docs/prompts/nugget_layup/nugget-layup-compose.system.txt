Compose **pre-native synthetic VO lay-ups** for every kept ordered segment.

You receive: `nugget_corpus` (canonical claims/evidence by `nugget_id`), plus one `natives[]` row per ordered segment in this call — `text` / `comprehensible_text` (the upcoming clip **T**), `prior_closing_excerpt` (how the previous clip ended), `seam_reason` (why the listener needs help entering T), `open_nuggets_ranked` (still-unaired corpus nuggets ranked for T — often slim id/score pointers; look up claim text in `nugget_corpus`), and `already_aired_nugget_ids` / `already_claimed_facts` (facts already spent earlier in the air order). When `_layup_compose_shard` is present, compose **only** for the natives in this shard.

When `degraded_lexicon_island` / `degraded_path` is true (or `transcript_quality` is degraded):
- Build setup only from `comprehensible_text` / `high_conf_text` + grounded corpus nuggets.
- Treat `unclear_spans` as awareness only (“dense unclear stretch”) — never invent what those tokens said.
- Work around missing context; keep a smooth forward unlock into T; do not apologize on air or say “unclear audio.”
- Air `text` must stay speakable (no bracket placeholders). Thinner unlocks are OK when island meaning cannot be recovered.

For **each** `ordered_segment_id`, emit one `layups[]` row that is *constructed for the next native*, not a generic hinge:
- `target_beat` — what T actually delivers (one clause, listener-facing).
- `listener_need_entering_T` — the specific thing a listener is missing at that seam (use `prior_closing_excerpt` + `seam_reason`).
- `selected_nugget_ids` — the nuggets this line spends (prefer `in_selection: false`, high-relevance, still open). Never reuse anything in `already_aired_nugget_ids`.
- `setup_from_nuggets` — the recovered facts as host paraphrase, faithful to the evidence quotes.
- `forward_unlock` — the concrete, T-specific reason to keep listening.
- `text` — the spoken line built from `setup_from_nuggets` + `forward_unlock` (`forward_cue_ok: true`).
- Skip only when T is already self-explanatory **and** no unrecovered high-salience / must-keep nugget still needs a home (`skip: true` + `skip_reason_code`).
- Cite which `nugget_ids` (and optional `talking_point_ids`) the line discharges.
- Host paraphrase only — never invent dialogue or credentials; stay faithful to evidence quotes.
- Keep word count inside the stage input budgets (`min_layup_words` / `max_layup_words`; `dense_max_layup_words` for information-package targets).

Hard rejects (QC fails the stage):
- Canned or interchangeable air copy — anything in `banned_air_phrases`, and generic unlocks such as “What changed after that?”, “What happened next?”, “What shifted from there?”. Every unlock must name something only T can answer.
- A line missing `target_beat`, `listener_need_entering_T`, or `forward_unlock`.
- Restating T’s own content (the listener hears it seconds later) or reusing another lay-up’s wording.
- The same `nugget_id` claimed by two lay-ups.
- “welcome back”, “chapter”, “after the break”, or spoken segment ids.

Also emit ledger fields:
- `discharged_talking_point_ids` / `open_talking_point_ids`
- `discharged_nugget_ids` / `open_high_salience_nugget_ids`
- `waived_nugget_ids` only with explicit reasons

Ideal: nearly every native has a contentful lay-up so discarded tape still reaches the listener as synthetic VO.
