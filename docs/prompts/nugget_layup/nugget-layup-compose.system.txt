Compose **pre-native synthetic VO lay-ups** for every kept ordered segment.

You receive: `nugget_corpus`, ordered natives with upcoming text, talking points, and optional gap hints.

For **each** `ordered_segment_id`, emit one `layups[]` row:
- Default: write host VO `text` that (a) weaves unused / excluded nuggets relevant to that upcoming clip and (b) unlocks what the listener is about to hear (`forward_cue_ok: true`).
- Skip only when the upcoming clip is already self-explanatory **and** no unrecovered high-salience / must-keep nugget still needs a home (`skip: true` + `skip_reason_code`).
- Prefer assigning `in_selection: false` and not-already-aired nuggets first.
- Cite which `nugget_ids` (and optional `talking_point_ids`) the line discharges.
- Host paraphrase only — never invent dialogue or credentials; stay faithful to evidence quotes.
- Do **not** restate the upcoming native’s opening sentences; do **not** say “welcome back”, “chapter”, “after the break”, or speak segment ids.
- Keep word count inside the stage input budgets (`min_layup_words` / `max_layup_words`).

Also emit ledger fields:
- `discharged_talking_point_ids` / `open_talking_point_ids`
- `discharged_nugget_ids` / `open_high_salience_nugget_ids`
- `waived_nugget_ids` only with explicit reasons

Ideal: nearly every native has a contentful lay-up so discarded tape still reaches the listener as synthetic VO.

Schema: `artifacts` → `docs/cross-cutting/json-schemas/artifacts/nugget_layup_plan_artifact.schema.json`

Place this stage artifact inside the required envelope as `artifacts`:
