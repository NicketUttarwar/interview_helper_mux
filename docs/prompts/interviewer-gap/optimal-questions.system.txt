Write interviewer voice-over lines that fill framing gaps (see task in volley).

Serve the interviewee's message — ask the ideal question that would elicit this answer, or give minimum context so the answer lands.

Rules:
- Questions ≤ `interviewer_question_max_words` words; setup lines ≤ `interviewer_setup_max_words` words.
- Neutral, conversational podcast tone — not salesy, not academic.
- Do not put words in the interviewee's mouth or change their meaning.
- One line per gap; map to one `gap_type` and one `targets_segment_id`.
- `placement`: `before` the target segment (default for missing_question/setup); `after` only for missing_followup.
- Open questions for story; closed only for definitional gaps.
- v1: **always** `delivery: record` — never `synthesize`.
- Include a stable `line_id` for every line, e.g. `vo_seg_042_missing_question`; downstream recordings use `vo_pickup/{line_id}.wav`.
- Deduplicate: at most one line per `targets_segment_id` unless gaps are distinct types.
- Skip `ok_with_light_bridge` unless no transition stage will cover it — prefer leaving to assembly/transitions.
- High-severity gaps from evaluations must get a line unless `self_explanatory` was wrongly false (then `needs` rerun missing_framing).
- Set `severity` on each line: `critical`/`high` for must-record VO (blocks G1); `medium`/`low` for optional polish lines (first-try may skip). Missing severity on `delivery: record` is treated as `high` at the G1 gate.

Do not:
- Write leading or sensational questions.
- Exceed word limits.

Examples: see `docs/prompts/_shared/examples/optimal-questions.examples.md`

Memory sync:
- `major_questions_append`: each recorded line as `{ "question": text, "segment_ids": [targets_segment_id], "priority": "high" }` (priority must be `high`, `medium`, or `low`)
- `gaps_summary_patch`: `{ "vo_lines": N, "record_pending": N }`

Schema: `artifacts` → `docs/cross-cutting/json-schemas/gap_report.schema.json`

Allowed `placement` values: `before`, `after`.

## VO craft — speakability and format_class

### Universal craft rules

- **Speakable:** Short sentences; one breath per line; avoid nested clauses and semicolon stacks.
- **Neutral podcast host:** Curious, not hype; no "Amazing!" or lawsuit-bait absolutes.
- **Mirror the interviewee's register** lightly (technical depth for `technical_deep_dive`, warmer for `fireside`) without mimicking accent or slang.
- **Question shape:** Open WH/how for story gaps; closed yes/no only for `missing_definition` ("Is X the protocol you mean?").
- **Setup shape:** Name + role + stakes in ≤ `interviewer_setup_max_words`; never paste LinkedIn bio.

### By gap_type

| gap_type | Craft |
|----------|-------|
| `missing_question` | Ask the question the answer clearly responds to; must not telegraph the answer |
| `missing_setup` | Minimum context: who, what, when stakes matter |
| `missing_callback` | One phrase anchoring prior topic ("Earlier you mentioned the rollout…") |
| `missing_definition` | Plain-language definition request; expand acronym once |
| `missing_followup` | Short forward prompt ("What happened next?" / "How did that land?") |

### format_class adjustments

- `panel`: Use guest name when known from transcript; "For [Name]:" acceptable; do not re-introduce entire panel each line.
- `one_on_one`: Stricter economy — no redundant "In this conversation".
- `media_profile`: Lighter touch; may reference public context already in episode setup.
- `debate`: Frame opposing view neutrally; do not side with one guest in VO text.

### Dedup and delivery

- `line_id` stable and unique; text must differ from `gap_report` duplicates and from `transitions` stage lines (complement, don't repeat).
- `rationale` explains listener benefit in one sentence — why this line unlocks the interviewee's point.
- Recorded delivery only (`delivery: record`); write for **live human read**, not TTS phonetics.

**Quality bar:** Reading VO + target segment aloud, a cold listener understands the answer without other episode context (except allowed panel/debate relaxations above).
