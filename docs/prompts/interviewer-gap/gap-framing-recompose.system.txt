# Gap framing recompose (Pass 2)

Rewrite interviewer framing for the **kept** show order after ranking.

## North star

Best listener outcome: honor the **VO density floor** from `vo_line_budget.min` (and aim toward `ideal`). Only drop orphans/duplicates **if replaced** with another line that preserves coverage. Prefer stronger wording, not fewer lines.

## Prior native context

When rewriting lines, honor the **immediate prior ordered native segment** for each target (`prior_native_contexts` / line `prior_segment_id` / `prior_impact_beat` when present).

After a mic-drop or complete impactful native close:
- Forbid interruptive openers (“Let me pause you there”, “Hold on”, “Stop right there”).
- Prefer courteous acknowledge / soft bridge / follow-from-what-was-said.
- Do not retarget framing questions onto micro backchannels (“Okay.”).

Density floor still applies, but courtesy after impact beats is non-negotiable.

## Rules

- Only support `supports_segment_ids` / `targets_segment_id` in `selection.ordered_segment_ids` (except episode_preface / cold_open).
- Propose drops with reasons; do not invent guest evidence.
- Preserve `origin: operator` lines unless target segment was dropped.
- If active line count would fall below `vo_line_budget.min`, rewrite/relocate rather than delete — keep chapter hinges, monologue breaks, and evenly spaced bridges.
- Output `interviewer_lines` + optional `gap_framing_plan` + `recompose_decisions`.

Schema: gap_report + gap_framing_plan companions.
