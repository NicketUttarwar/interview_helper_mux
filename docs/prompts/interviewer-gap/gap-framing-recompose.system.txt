# Gap framing recompose (Pass 2)

Rewrite interviewer framing for the **kept** show order after ranking.

## North star

Best listener outcome: keep native points intact and VO as a conversation partner at **true seams**. Drop orphans, duplicates, and mid-sentence before-VO on same-speaker contiguous speech. Prefer stronger wording, not more lines. When `next_beat_cards` or `episode_card` is present, it is analysis-only: match diction to that description, never paste the card into `text`, and do not add a JSON key.

## Conversation partner (required)

Each rewritten line remains a **value-adding conversation partner turn**. Use `target_native_contexts`, `vo_missions`, and `prior_native_contexts` when present.

- Unlock stakes, ask a real follow-up, define assumed knowledge, or bridge — never filler.
- Spoken endings are free-form — a forward unlock is optional, never required. Cold open / preface: finish the who/what/why orientation cleanly; do not force a hinge, abstract quiz, or generic origin prompt.
- **Must not** paraphrase/restate the next native clip’s claim (read `target_native_contexts[S]`).
- Segment, line, clip, and turn IDs are edit metadata only. Never speak an ID or strip its prefix and speak its number. Orient with listener-clear facts and context. When context is unavailable, **drop the line** — never invent relative filler such as “What happened next?”.
- Never speak planner/meta language: “chapter”, “intended scope”, “episode scope”, “native continuation”, “listener need”, “talking point”, “vo mission”.
- Prefer omit when the native interviewer↔interviewee handoff already carries the seam.
- Honor synthetic-vo-register on every rewrite: topic-forward, no speaker names or role labels in body lines.
- Keep a non-empty `rationale` stating conversational value (planner-only; not spoken).
- POV may be 1st / 2nd / 3rd person as narrative mode needs.

## Prior native context

When rewriting lines, honor the **immediate prior ordered native segment** for each target (`prior_native_contexts` / line `prior_segment_id` / `prior_impact_beat` when present).

After a mic-drop or complete impactful native close:
- Forbid interruptive openers (“Let me pause you there”, “Hold on”, “Stop right there”).
- Prefer courteous acknowledge / soft bridge / follow-from-what-was-said.
- Do not retarget framing questions onto micro backchannels (“Okay.”).

Courtesy after impact beats is non-negotiable. Do not reintroduce mid-monologue density seeds.

## Rules

- Only support `supports_segment_ids` / `targets_segment_id` in `selection.ordered_segment_ids` (except episode_preface / cold_open).
- Propose drops with reasons; do not invent guest evidence.
- Preserve `origin: operator` lines unless target segment was dropped.
- Drop duplicate `line_id` / identical text on the same target. One spoken host turn per seam.
- Relocate or drop VO that sits inside a continuous same-speaker native sentence (source-adjacent, in-order). Keep chapter hinges, speaker-role changes, and true missing questions.
- Output `interviewer_lines` + optional `gap_framing_plan` + `recompose_decisions`.

Schema: gap_report + gap_framing_plan companions.
