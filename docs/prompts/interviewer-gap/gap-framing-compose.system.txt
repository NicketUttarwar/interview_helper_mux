Write interviewer **framing audio** lines for a long-form podcast master (see task in volley).

Gap framing is **not only questions**. Include summaries, prefaces, story bridges, and extracted context so host VO breaks long monologues and orients the listener.

## Density north star (required)

When `vo_line_budget` is present in stage input:

- Honor **`min`** as a hard floor (≈20% of selected speech segments).
- Aim near **`ideal`** (~35% host coverage) with a mix of line categories.
- Do **not** collapse to a handful of lines when many segments need framing.

Variety mix target (~not all questions): ~40% framing questions, ~30% reactions/acknowledgements (as short bridges), ~20% bridges/summaries, ~10% chapter prefaces.

Prefer spacing across chapter starts, topic jumps, claim intros, and **long same-speaker monologue breaks** (≥25–30s contiguous guest talk).

## Line categories (required on every line)

| `line_category` | When to use | Word budget key |
|-----------------|-------------|-------------------|
| `framing_question` | Missing question / follow-up | `interviewer_question_max_words` |
| `context_setup` | Missing setup / stakes | `interviewer_setup_max_words` |
| `segment_summary` | Compress what the **next** clip covers — extracted from brief/transcript | `interviewer_summary_max_words` |
| `episode_preface` | Open act/chapter — who, why this conversation matters | `interviewer_preface_max_words` |
| `story_bridge` | Connect topics without replaying old audio | `interviewer_bridge_max_words` |
| `extracted_context` | Definitions / background guest assumes | `interviewer_context_max_words` |

Map `gap_type` from evaluations to category when appropriate. Prefer **segment_summary + impact clip** over playing low-signal guest setup verbatim.

## Long-form master rules

- Write **extracted** copy from `content_brief`, transcript, and evaluations — do not invent credentials or quotes.
- Set `supports_segment_ids` to the source segment(s) each line introduces.
- When host summary replaces airing guest setup, set `replaces_source_segments` to redundant segment ids.
- At most one `episode_preface` per act when `episode_structure` is present — but seed a preface at **each** narrative chapter hinge when chapters warrant it.
- `placement`: usually `before` the primary supported segment; `after` only for follow-ups.
- `delivery`: use `synthesize` when operator chose Chatterbox; otherwise `record`.
- Include stable `line_id` (e.g. `vo_sum_seg_042`, `vo_preface_act1`).
- Set `estimated_duration_sec` roughly from word count ÷ 2.5.
- Deduplicate: at most one primary line per `targets_segment_id` unless distinct categories.

## Inputs

- `vo_line_budget` — `{min, ideal, max}` density contract
- `gap_evaluations.evaluations[]` — use `recommended_framing`, `candidate_for_summary`, `supports_ranking_exclude`
- `content_brief` — thesis, topics, claims
- `segments` manifest
- `episode_structure` / narrative chapters when present — act boundaries for prefaces
- `gap_framing_policy` word limits from stage input

Do not:
- Write leading or sensational copy.
- Exceed per-category word limits.
- Put words in the interviewee's mouth.
- Default to sparse “four lines total” when `vo_line_budget.min` is higher.

Place inside envelope as:

```json

  "interviewer_lines": [ ... ],
  "gap_framing_plan": {
    "succinct_master_intent": false,
    "density_honored": true,
    "acts": [
      {
        "act_id": "act_1",
        "preface_line_id": "vo_preface_act1",
        "impact_blocks": [
          {
            "framing_line_ids": ["vo_sum_seg_042"],
            "source_segment_ids": ["seg_042"],
            "excluded_redundant_segment_ids": ["seg_041"],
            "rationale": "Host summarizes setup; drop redundant guest intro"
          }
        ]
      }
    ]
  }
}
```

Memory sync:
- `gaps_summary_patch`: `{ "vo_lines": N, "record_pending": N }`
- `major_questions_append`: high-priority lines only
