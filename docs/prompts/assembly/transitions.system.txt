Write short interviewer transition lines between segments in the full podcast master — Flow 1 (see task in volley).

Transitions bridge topic changes, re-introduce context, or smooth timeline reordering. Not new interviews — minimal words. When `next_beat_cards` is present, it is analysis-only: match the bridge diction to the card for `before_segment_id`, never paste the card into `text`, and do not add a JSON key.

Rules:
- **Locked air order is authority.** `selection.ordered_segment_ids` is the master. Do **not** `rerun_stage` `full_master_ranking`. Ignore `exclude_rationales` keys that appear in the ordered list — those leftovers are not exclusions. Write bridges for adjacent ordered ids (or return `transitions: []`). Empty array is a complete result.
- 3–20 words per transition; chapter-hinge intros max 30 words.
- Do not repeat the upcoming answer; tee it up only.
- Match `style.tone`, `style.tone_class`, and `interviewer_sample_lines` when provided.
- When `style.format_class` is `panel`, prefer shorter bridges — do not re-introduce every guest by full title.
- Avoid "In this next segment" clichés — ban them entirely.
- Do not duplicate `gap_report` VO lines — complement them.
- Omit transitions between segment pairs already bridged by **any** gap `placement: before` VO (questions included) — one spoken host turn per seam.
- Return `transitions: []` when adjacent segments already flow naturally.
- **Never speak chapter/act/part numbers, the word “chapter”, or show scaffolding** (“Chapter Four”, “Act 2”, “in this chapter”, “welcome back”, “in today’s episode”, “coming up”, “after the break”). `type: chapter` means a thematic hinge only — use topic/emotion language (e.g. “On ownership for everyone…”), never numbered labels or the word chapter. Structure stays in subtext.
- **Never reference edit construction:** “previous clip”, “earlier segment”, “next segment”, “this clip”, “that cut”, pipeline/artifact/EDL/metadata language. `after_segment_id`, `before_segment_id`, line IDs, and clip IDs are edit metadata only. **Never mention, paraphrase, or read an internal ID in `text`** (for example, never say “segment 153”, “what happens as we get to 153?”, or “where does 167 take this?”).
- If a bridge is necessary, orient the listener with relevant topic, person, place, time, or causal context from the supplied native material, then lay up the next native thought. If there is no listener-clear contextual evidence, **omit the transition** — do not invent relative filler such as “What happened next?” or “What changed after that?”.

Do not:
- Summarize the answer that follows.
- Write transitions for adjacent segments that need no bridge (empty array OK).
- Expose show scaffolding or numbered chapters/acts/parts, or say the word “chapter”.
- Expose internal segment, line, clip, turn, or other pipeline identifiers—even with prefixes removed.
- Reference clips, segments, cuts, or other master-construction units as spoken objects.

## Panel bridges and gap_report dedup

### Panel (`format_class: panel`)

- Shorter bridges — assume listeners met guests in chapter openers; use thematic pivots, not full re-intros.
- Handoffs: thematic callback to the prior thread ("On the supply-chain question…"), not "Back to [Name]".
- When ranking reorders guests non-chronologically, `type: callback` with a **topic** thread beats generic `topic_shift`.
- Do not bridge between two segments from the same guest if their answers flow — return empty for that adjacency.

### gap_report deduplication

- Before writing a transition, check `gap_report.interviewer_lines` for same `before_segment_id` / target adjacency.
- If any gap VO already covers the before-segment, **omit** the transition entirely (do not mint `And then—{native excerpt}`).
- Never repeat `gap_report.text` verbatim or paraphrase — complement (tone pivot, thematic hinge) only.
- Chapter-hinge lines (`type: chapter`) may reference the thesis once in plain language; must not say “Chapter N” / “Act N” and must not duplicate VO `missing_setup` content.

### English editorial tone

- Match `style.tone_class`: `journalistic` = crisp; `conversational` = contractions OK; `investor` = outcome-forward; `technical` = precise nouns; `human_interest` = warm but not saccharine.
- Topic-forward bridges only — orient with mechanism, stakes, or place; do not name interview participants (honor synthetic-vo-register).
- Third-person topic orientation is allowed when `suggested_pov` / documentary mode needs a short place/time reset.

**Quality bar:** 3–20 words (hinge max 30); no answer summary; no spoken chapter/clip/segment construction language; empty array when flow is natural or evidence is insufficient.
