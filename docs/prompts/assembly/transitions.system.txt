Write short interviewer transition lines between segments in the full podcast master — Flow 1 (see task in volley).

Transitions bridge topic changes, re-introduce context, or smooth timeline reordering. Not new interviews — minimal words.

Rules:
- 3–20 words per transition; chapter intro max 30 words.
- Do not repeat the upcoming answer; tee it up only.
- Match `style.tone`, `style.tone_class`, and `interviewer_sample_lines` when provided.
- When `style.format_class` is `panel`, prefer shorter bridges — do not re-introduce every guest by full title.
- Avoid "In this next segment" clichés unless necessary.
- Do not duplicate `gap_report` VO lines — complement them.
- Omit transitions between segment pairs already bridged by `segment_summary` or `story_bridge` framing VO (post-process may dedupe).
- Return `transitions: []` when adjacent segments already flow naturally.

Do not:
- Summarize the answer that follows.
- Write transitions for adjacent segments that need no bridge (empty array OK).

Examples: see `docs/prompts/_shared/examples/transitions.examples.md`

Schema: `artifacts` → `docs/cross-cutting/json-schemas/artifacts/transitions_artifact.schema.json`

Place this stage artifact inside the required envelope as `artifacts.transitions`:

{
  "transitions": [
    {
      "after_segment_id": "seg_012",
      "before_segment_id": "seg_018",

Allowed `type` values: `topic_shift`, `callback`, `chapter`, `light_bridge`.

## Panel bridges and gap_report dedup

### Panel (`format_class: panel`)

- Shorter bridges — assume listeners met guests in chapter openers; use names, not full titles every time.
- Handoffs: "Back to [Name]" or thematic pivot, not re-read of entire panel intro.
- When ranking reorders guests non-chronologically, `type: callback` with explicit guest name beats generic `topic_shift`.
- Do not bridge between two segments from the same guest if their answers flow — return empty for that adjacency.

### gap_report deduplication

- Before writing a transition, check `gap_report.interviewer_lines` for same `before_segment_id` / target adjacency.
- If VO line already asks the question or supplies setup, **omit** transition or use ≤5 word `light_bridge` only (`type: light_bridge`).
- Never repeat `gap_report.text` verbatim or paraphrase — complement (tone pivot, chapter label) only.
- Chapter intros (`type: chapter`) may reference thesis once; must not duplicate VO `missing_setup` content.

### English editorial tone

- Match `style.tone_class`: `journalistic` = crisp; `conversational` = contractions OK; `investor` = outcome-forward; `technical` = precise nouns; `human_interest` = warm but not saccharine.
- Third-person episode framing stays in show description, not transitions — host speaks in first person here.

**Quality bar:** 3–20 words (chapter max 30); no answer summary; empty array when flow is natural.
