Classify interview segments for downstream editing and gap analysis (see task in volley).

Segment types:
- interviewer_question — explicit or clearly implied question
- interviewee_answer — main response
- interviewer_reaction — brief backchannel ("yeah", "right", "interesting")
- setup — interviewer context before a topic
- aside — tangential; often trimmed in full master
- coda — closing/wrap-up

Rules:
- Use `content_brief.topics[].name` as `topic_tags` when they fit; otherwise infer 1–3 short snake_case tags.
- Mark `starts_mid_thought`, `references_prior_missing`, `heavy_crosstalk` in `flags` when applicable.
- `references_prior_missing` often becomes `missing_callback` in gap pass — flag honestly.
- For shard/collate runs, union segments by `segment_id`. If duplicate segment classifications disagree, keep the one with stronger transcript evidence and note ambiguity in `reasoning_summary`.

Do not:
- Tag every segment `interviewee_answer`.
- Invent topic names that contradict the content brief.

Memory sync:
- `themes_append`: update `segment_ids` for themes you can map from tags

Investigations:
- `theme_unmapped` when a content brief topic has zero segments tagged.
- `segment_ambiguity` when boundary intent is unclear (type contradicts text).

Examples: see `docs/prompts/_shared/examples/segment-classification.examples.md`

Schema: `artifacts` → `docs/cross-cutting/json-schemas/artifacts/manifest_artifact.schema.json`

Place this stage artifact inside the required envelope as `artifacts.segments`:

{
  "segments": [
    {
      "segment_id": "seg_001",
      "type": "interviewee_answer",
      "speaker_id": "spk_00",
      "speaker_role": "interviewee",
      "topic_tags": ["string"],
      "flags": ["starts_mid_thought", "references_prior_missing", "heavy_crosstalk"]
    }
  ]
}

Allowed `type` values: `interviewer_question`, `interviewee_answer`, `interviewer_reaction`, `setup`, `aside`, `coda`.
Allowed `speaker_role` values: `interviewer`, `interviewee`, `unknown`.
Allowed `flags` values: `starts_mid_thought`, `references_prior_missing`, `heavy_crosstalk`.
