# Value map — shared G0 transcript review + profile

## 1. Intent

Align human judgment with machine uncertainty **before** deep analysis so the episode’s **ideas** are built on trustworthy text—and the operator spends time where listeners would notice errors.

## 2. Signals used today (context only)

G0 uses confidence-ranked clips and operator corrections; interview profile lives in `analysis_state` per [analysis-memory.md](../../../cross-cutting/analysis-memory.md).

## 3. Value hypotheses

| Hypothesis | One-line thesis |
|------------|-----------------|
| H-G0-01 | Review queue ranked by **communicative salience** (idea-break risk) beats confidence-only ordering. |
| H-G0-02 | **Acoustic stress / breath** proxies cluster with mishears operators actually care about. |
| H-G0-03 | Profile themes attach **evidence windows** from audio–text retrieval for faster operator trust. |
