# Agent swarm protocol — Heal Clinic

## Law

- No product patches in Wave 1.
- No deciding for the operator — recommend only.
- Code is king; merge minority findings into the map/options, do not drop them silently.
- Simple language in TL;DR and worst cases.

## Per-class swarm (spawn as many as needed)

| Role | Writes | Must not |
|------|--------|----------|
| Mechanism census | possibility.md caller tables | patch |
| Residual verifier | closed-vs-open vs cousin_matrix / DPs on HEAD | treat HINT as proof |
| Surgical option author | `solution_swarm/option_A_*.md` | sole final packet |
| SSOT / bigger-deterministic author | `solution_swarm/option_B_*.md` | sole final packet |
| Alternate / CUT / gate author | `solution_swarm/option_C_*.md` | suppress Defer |
| Devil’s advocate | attack leading recommendation | delete options |
| Test/matrix designer | suggested `MUX_FORENSICS=0` tests | patch |
| Cousin scout | cross_class_patterns draft rows | patch |
| **Merge captain** | final `options.md` (≥A/B/C/Defer, recommendation, cousins) | one-option packets; jargon-only TL;DR |

## Parallelism

No agent-count budget. Five classes may run in **five separate Cursor Agent chats**. Inside one class, swarm in parallel then merge.

## After merge

Stop for operator with YOUR NEXT ACTIONS + `/heal-clinic-answer` examples + `/heal-clinic-next`.
