# High-risk stage audits

Per-stage investigation notes for stages in
[`../high_risk_error_stages_report.md`](../high_risk_error_stages_report.md).

**Operator:** paste one command in a new chat (replace `___` with seed # or stage id):

```
/high-risk-audit STAGE=___
Follow .cursor/skills/high-risk-stage-audit/SKILL.md
```

Each audit starts with §0 Stage Guide (what the stage does, rules, considerations), then over-engineering evaluation. Skill: [`.cursor/skills/high-risk-stage-audit/SKILL.md`](../../skills/high-risk-stage-audit/SKILL.md).
